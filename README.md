# procedural-map-seed-server

Серверная часть интернет-ресурса для генерации процедурных игровых карт по сид-значениям.

Курсовая работа по дисциплине «Проектирование и разработка серверных частей интернет-ресурсов», направление 09.03.04 «Программная инженерия», РТУ МИРЭА, кафедра ИиППО.

## Описание

Сервис принимает сид (целое число) и параметры области карты и возвращает карту из клеток четырёх типов: вода, равнина, лес, горы. Генерация детерминированная: один и тот же сид с одними и теми же координатами и размером всегда даёт одну и ту же карту. Поэтому готовые карты не хранятся, а восстанавливаются по сиду.

## Цель

Разработать веб-приложение, которое генерирует процедурные игровые карты по сид-значениям, отображает их в браузере, предоставляет JSON-API и сохраняет статистику запросов в базе данных.

## Стек

- PHP 8.3+, Laravel 13
- SQLite по умолчанию; подключение MySQL или PostgreSQL задаётся в `.env`
- HTML5, CSS3 (без сборщиков и CSS-фреймворков)
- Архитектура: MVC с выделенным слоем сервисов (`app/Services/MapGen`, `app/Services/MapStats`)

## Возможности

- Страница ввода сида и просмотра карты с легендой.
- Перемещение области карты вправо кнопкой «Сдвинуть вправо».
- JSON-API для получения карты.
- История запросов: таблица `map_requests` хранит, сколько раз запрашивалась каждая область карты. Обращения через веб-страницы и через API учитываются вместе.
- Тесты на воспроизводимость генерации, валидацию параметров и подсчёт запросов.

## Маршруты

| Метод | Путь | Описание |
|---|---|---|
| GET | `/maps` | Форма ввода сида |
| GET | `/maps/search?seed=42` | Перенаправление на страницу карты |
| GET | `/maps/{seed}` | Страница карты |
| GET | `/api/maps/{seed}` | Карта в формате JSON |

Необязательные параметры запроса: `x` и `y` — координаты левого верхнего угла области (по умолчанию 0), `width` — ширина в клетках (по умолчанию 40), `height` — высота (по умолчанию 20).

Пример: `/api/maps/42?x=10&y=5&width=20&height=10`.

## Установка и запуск

Требования: PHP 8.3 или новее с расширением `pdo_sqlite`, Composer.

```bash
composer install
cp .env.example .env
php artisan key:generate
touch database/database.sqlite
php artisan migrate
php artisan serve
```

В Windows (PowerShell) вместо `cp` используйте `copy`, а вместо `touch` — `New-Item database\database.sqlite`.

В файле `.env` для локального запуска укажите `APP_URL=http://127.0.0.1:8000`.

После запуска откройте http://127.0.0.1:8000/maps.

## Консольная команда

```bash
php artisan map:show 42 --width=40 --height=20
```

Выводит карту в терминал: `~` — вода, `.` — равнина, `T` — лес, `^` — горы.

## Тесты

```bash
php artisan test
```

Набор содержит 30 тестов: генератор и ГСЧ, маршруты, API, валидацию параметров и подсчёт статистики.

## Структура

- `app/Services/MapGen` — генерация карты: `SeededRandom` (SplitMix64), `MapGenerator`, `TileType`
- `app/Services/MapStats` — запись статистики запросов
- `app/Http/Controllers/MapController.php` — страницы карты
- `app/Http/Controllers/Api/MapApiController.php` — JSON-API
- `app/Http/Requests/MapParamsRequest.php` — валидация сида и параметров области
- `app/Models/MapQuery.php` — модель таблицы `map_requests`
- `resources/views/maps/`, `resources/views/layouts/app.blade.php` — страницы и общий каркас
- `public/css/app.css` — стили (сборка не требуется)
