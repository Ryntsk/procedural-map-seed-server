# procedural-map-seed-server

Серверная часть сервиса генерации процедурных игровых карт по сид-значениям.

Курсовая работа по дисциплине «Проектирование и разработка сервисов» (ПиРСЧИР), РТУ МИРЭА.

## Описание

Сервис принимает сид и параметры карты и возвращает игровую карту в виде данных. Генерация детерминированная: один и тот же сид с одними и теми же параметрами всегда даёт одну и ту же карту. Это позволяет не хранить готовые карты, а восстанавливать их по сиду на сервере или клиенте.

## Цель

Разработать серверную часть сервиса, которая генерирует процедурные игровые карты по сид-значениям, предоставляет их через HTTP API и гарантирует воспроизводимость результата.

## Основные возможности (план)

- Генерация карты по сиду и параметрам (размер, тип местности и т. п.).
- Эндпоинт `GET /maps/{seed}` с необязательными параметрами.
- Гарантия воспроизводимости: одинаковый сид даёт одинаковую карту.
- Тесты на детерминированность и корректность генерации.

## Стек

Будет уточнён. Планируемые компоненты: серверный фреймворк, генератор карт, тестовый набор.
