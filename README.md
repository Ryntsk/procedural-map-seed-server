# procedural-map-seed-server

Серверная часть интернет-ресурса для генерации процедурных игровых карт по сид-значениям.

Курсовая работа по дисциплине «Проектирование и разработка серверных частей интернет-ресурсов», направление 09.03.04 «Программная инженерия», РТУ МИРЭА, кафедра ИиППО.

## Описание

Сервис принимает сид (seed) и параметры карты и возвращает игровую карту. Генерация детерминированная: один и тот же сид с одними и теми же параметрами всегда даёт одну и ту же карту. Это позволяет не хранить готовые карты, а восстанавливать их по сиду.

## Цель

Разработать веб-приложение, которое генерирует процедурные игровые карты по сид-значениям, сохраняет запросы в базе данных и отображает карты в браузере.

## Стек

- PHP 8.2+, Laravel
- MySQL / PostgreSQL (уточняется)
- HTML5, CSS3
- Архитектурный паттерн: MVC с выделенным слоем сервисов

## Возможности

- Генерация карты по сиду и параметрам (размер, тип местности).
- Страница для ввода сида и просмотра карты.
- История сгенерированных карт в БД.
- API-эндпоинт `GET /api/maps/{seed}`.
- Тесты на воспроизводимость генерации.
